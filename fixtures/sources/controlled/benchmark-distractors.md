# 受控基准干扰证据

本文档只用于构造知识环境基准中的控制变量，不代表真实工程建议，也不得作为项目实施依据。每条三级标题下只有一条独立干扰主张，编号用于建立可审计的时效或冲突关系。

## 主题 01：规范 JSON 哈希

### DIST-01-OLD

已过时声明：配置身份可以直接对 Python 字典的字符串表示计算哈希，因为字典当前的插入顺序已经足以保证跨进程、跨语言和跨构造顺序的一致性。

### DIST-01-ALT

冲突候选声明：生成配置身份前不仅要按键排序映射，还必须对所有数组元素统一排序；数组原有顺序不属于配置语义，任何数组顺序变化都不应改变哈希。

## 主题 02：冻结容器

### DIST-02-OLD

已过时声明：只要 Pydantic 模型设置 `frozen=True`，字段中的普通 `list` 就会自动变成深度不可变对象，因此列表原地追加不会影响冻结模型。

### DIST-02-ALT

冲突候选声明：冻结模型应继续公开 `list` 字段，并用自定义不可变 `list` 子类覆盖 `append` 等方法；这种子类能可靠阻止所有基类方法、深复制和 Pickle 路径修改内容。

## 主题 03：测试驱动开发

### DIST-03-OLD

已过时声明：实现功能后再补测试与先写失败测试等价，只要最终覆盖率足够高，就无需观察测试因目标行为缺失而失败。

### DIST-03-ALT

冲突候选声明：可以先保留完整实现作为参考，再编写不会执行的测试草稿，最后一次性运行绿灯；该流程仍属于严格的测试驱动开发。

## 主题 04：双级审查

### DIST-04-OLD

已过时声明：原实现者完成一次自审即可同时替代规格审查和代码质量审查，不需要独立审查者或固定的审查顺序。

### DIST-04-ALT

冲突候选声明：双级审查应先做代码质量审查，再做规格审查；即使规格后来发现少做或多做，先前的质量结论仍可直接沿用。

## 主题 05：模块边界

### DIST-05-OLD

已过时声明：基准模块应直接执行 Agent Runtime 和联网搜索，以便在构造样本时同时得到最终答案与评测标签。

### DIST-05-ALT

冲突候选声明：语料模块应负责 BM25 排名、知识充分性判断和是否联网的决策，从而让所有证据处理集中在同一个包内。

## 主题 06：Agent 框架消息契约

### DIST-06-OLD

已过时声明：Agent、语言模型与工具之间只需传递未经结构化的单个字符串，角色、工具调用和历史消息都可以依靠字符串约定隐式解析。

### DIST-06-ALT

冲突候选声明：每轮调用只应保留最新用户文本，系统消息、助手消息和工具返回不应进入统一消息序列，以免消息类型增加框架复杂度。

## 主题 07：记忆分层

### DIST-07-OLD

已过时声明：智能体只需要一个无限增长的对话列表作为全部记忆，不必区分工作记忆、情景记忆、语义记忆或长期存储。

### DIST-07-ALT

冲突候选声明：智能体只应使用外部向量库保存长期记忆，当前任务的短期上下文无需工作记忆管理，也不需要遗忘、整合或分层机制。

## 主题 08：检索流程

### DIST-08-OLD

已过时声明：检索增强问答可以跳过文档解析、切分和索引，直接把完整原始文件与问题一次性放入模型上下文即可稳定完成检索。

### DIST-08-ALT

冲突候选声明：检索流程在召回候选块后应立即返回最高分块作为最终答案，不需要把检索上下文与用户问题交给生成阶段，也无需保留来源信息。

## 主题 09：评测指标

### DIST-09-OLD

已过时声明：智能体性能只需报告单一任务准确率，工具调用正确性、轨迹质量、成本、延迟和失败类型都不会改变评测结论。

### DIST-09-ALT

冲突候选声明：智能体评测应只优化平均响应延迟；只要延迟最低，即使任务失败或工具调用错误，也应判为总体性能最佳。

## 主题 10：评测数据隔离

### DIST-10-OLD

已过时声明：运行中的 Agent 可以直接读取答案键、目标类别、缺失主张和复核理由，因为这些字段能帮助它稳定输出正确答案。

### DIST-10-ALT

冲突候选声明：开发、运行、标签和审计数据应合并为一个 JSONL 文件，只需依赖调用方自觉忽略标签字段，不必采用物理文件隔离或白名单载荷。

## 主题 11：学习路线

### DIST-11-OLD

已过时声明：学习 Agent 工程应先一次性掌握所有框架、数学原理和分布式架构，再接触可运行的最小示例、测试或项目代码。

### DIST-11-ALT

冲突候选声明：学习路线只需复制完整框架代码并直接运行，学习者不必理解模块职责、数据流、验证命令或逐阶段练习。

## 主题 12：人工门禁

### DIST-12-OLD

已过时声明：两个模型给出一致结论即可自动写入人工 `approved`，模型一致意见在审计意义上等同于人工终审。

### DIST-12-ALT

冲突候选声明：只要复核模型置信度不低于 `0.8`，过时、冲突、曾经规则失败或被退回的样本都可以跳过人工审核并直接冻结。
