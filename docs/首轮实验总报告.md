# 首轮实验总报告

## 交付结论

受限运行时、动作循环轨迹重放、SQLite/BM25、充分性判断、验证写回、候选门禁、隔离评测和五阶段课程均已实现。真实实验完成三百八十四次主运行、四十八次复用运行、九十六次候选运行；另有八次开发冒烟和一次技能提炼。失败不删除、不挑题补跑。

效果结论是不支持初始效率收益假设：门禁相对有知识对照没有减少搜索；写回存在新增编号但缺少有效新信息复用；候选出现退化并被拒绝。工程机制可审计，不等于机制已经优于对照。二十四条高风险候选仍待真人终审，下列不是正式性能或生产结论。

## 数据、模型与复现身份

- 来源固定八份文档、三百一十六块；十二个主题各派生充分、部分覆盖、过时、冲突四环境，共四十八条候选。没有本地全缺失或真实网页任务子集。
- 开发主题01–04，主集05–12；同主题四环境不跨分割。三次重复不是九十六个独立主题，统计按八主题成簇。
- 模型为现有兼容服务自报 `deepseek-v4-flash`，温度零，固定关闭额外推理、输出上限1800、最大四步、网络超时90秒、最多一次传输重试。权重版本不可验证固定；本地重复种子没有传给远端采样。
- 数据摘要：`2d7570aaaf5b6b9eeacd0acd7f2262bbdb694b57aea40ecfebb910c4bc7dbf9e`。
- 协议摘要：`197872ff62775c2159f2da5f006c5917a76d71a19e5dcd2e310d64f009835387`；实际运行源码为 `2fba428`。后置完整性修订不重写原始数据，修订前后报告相等性单独验证。

## 知识与技能

复用二十四对中，新增条目进入输入15对，实际被引用4对；有/无写回搜索为24/23，未减少。成功为20/24与18/24，补充簇区间未排除零。进一步来源审计发现，四个实际复用条目都未引用原研究池缺失证据，不能宣称完成了新知识学习。见[复用报告](知识复用实验报告.md)。

候选目标得分47/48降至37/48，差−20.83个百分点；回归均分虽增加，但一对从成功变失败，下降比例2.08%，超过零阈值，门禁拒绝。平均令牌增加539.04。候选仅适用配置哈希，目标主题不直接覆盖该能力，因此还存在适用范围不对齐；不把结果泛化为所有技能有害，也不声称迁移已被有效验证。见[技能报告](候选技能门禁报告.md)。

## 工程核验与限制

全部384条主动作循环轨迹在阻断HTTP条件下重放通过；核验1131次主运行组件载荷，未发现禁用标签字段或排除池命中。外层充分性、提取、验证与评分另有原始调用，不属于动作循环重放的再次执行范围。

后置修订检查第一轮及技能配对身份、跨平台相对轨迹路径和迁移清单读取。只收紧读取与关联，不改阈值、评分或统计公式。最终测试与迁移证据见[交付清单](最终交付清单.md)；原审查、误报处置和红绿修复见[中间报告](reports/)。
