# 教程到实现的工程映射

本项目只选指定教程的工程部分，不安排前三章概念复述。下列为教学借鉴，不宣称教程证明本项目的效果，也不把教程中的所有组件照搬。来源固定提交、路径和正文摘要见 `fixtures/sources/manifest.json`；离线副本在 `fixtures/sources/raw/`。

## 学习路线：从作品到评测

- 解决什么问题：只读术语或只复制案例，无法判断是否掌握执行和评测。
- 怎么做的：学习路线按最小作品、工具与记忆、能力封装、评测和可观测性递进；每档有可运行产物。
- 输入数据：学习者代码、任务及观察记录组成离散集合，不是固定维度向量。
- 输出数据：五阶段共二十份材料、四十题、十个演示；每题有独立评分点。
- 与本文关联：`learning/README.md` 的三轮辅导、`demo/01` 至 `demo/10` 及阶段提交。格式测试检查契约，不证明学习效果。

固定来源：[学习路线](https://github.com/datawhalechina/Agent-Learning-Hub/blob/dddf777dde6788228136862f270203424a28efbc/README.md)。

## 第七章：消息与执行上下文

- 解决什么问题：运行模型看不到实际工具观察，或历史与动作混在无约束字符串中。
- 怎么做的：教程约束消息角色、正文与历史管理，分离模型调用接口。项目保留受限两动作循环，不照搬完整框架继承层。
- 输入数据：问题字符串 `q`、本地证据序列 `K ∈ E^k`、已有调用与观察 `H_t ∈ M^(n_t)`，其中长度随步数变化。
- 输出数据：一步结构化研究或作答动作，以及追加真实观察后的 `H_(t+1)`；停止时形成一份 `RunResult`。
- 与本文关联：`runtime/loop.py` 的 `make_payload/run_task`、`runtime/models.py` 的 `Action`、`tracing/store.py` 的保存与重放。提示词摘要与动作合法性是本项目增加的实验约束。

固定来源：[第七章](https://github.com/datawhalechina/hello-agents/blob/5caceca4e4c9a3d25cd14627881436953f4d6912/docs/chapter7/第七章%20构建你的Agent框架.md)。

## 第八章：记忆分层与检索

- 解决什么问题：把会话历史当永久知识，或把相关块当充分证据。
- 怎么做的：教程区分工作记忆与语义记忆，介绍异构文档处理和检索链路；项目用固定 Markdown 切块、BM25 与 SQLite 固定首轮变量，不增加向量模型。
- 输入数据：文档集合 `D={d_1,…,d_N}` 与查询 `q`；切块得到 `C={c_1,…,c_M}`，词频为标量 `f(t,c_j)`，非嵌入矩阵。
- 输出数据：最多 `k=4` 条带分数和正文的命中；充分性再单独输出标签、预测缺口、异常引用和置信度。
- 与本文关联：`corpus/chunking.py`、`retrieval/bm25.py` 的 `BM25Index`、`knowledge/store.py` 的 `search/as_evidence`；BM25 公式见阶段三。`assess` 的语义充分性不是 BM25 分数，也不读取评测主张。

固定来源：[第八章](https://github.com/datawhalechina/hello-agents/blob/5caceca4e4c9a3d25cd14627881436953f4d6912/docs/chapter8/第八章%20记忆与检索.md)。

## 第十二章：分层评测与验证

- 解决什么问题：只报最终准确率，无法解释工具、知识判断、引用与成本的贡献。
- 怎么做的：教程按任务选择多维指标并保留人工质量验证。项目将运行与评分分开，候选终审也与模型一致意见分开。
- 输入数据：留出八主题、每题四环境、每变体三重复，主运行成功向量 `s_v ∈ {0,1}^96`；每个主题含十二条相关观测。评分标签只由评测器读取。
- 输出数据：任务成功标量、二分类四格计数、真实用量，以及八个主题均值差经一千次簇采样得到的区间。复用与技能使用另行固定的配对关系。
- 与本文关联：`eval/grading.py` 的 `grade_answer`、`eval/metrics.py` 的 `summarize/paired_bootstrap`、`eval/report.py` 的 `build_report`。具体成功判据、保守分母及成簇统计为本项目预注册选择，不归称教程原公式。

固定来源：[第十二章](https://github.com/datawhalechina/hello-agents/blob/5caceca4e4c9a3d25cd14627881436953f4d6912/docs/chapter12/第十二章%20智能体性能评估.md)。

## 溯源总结图

```text
学习者代码与观察 → 可运行阶段作品 → 练习与评分点
问题 + 历史 + 实际证据 → 结构化动作 → 完整轨迹
文档 + 查询 → 切块与BM25 → 可见知识 → 充分性判断
冻结任务 + 已完成轨迹 + 隔离标签 → 多维指标 → 有范围的实验结论
```
