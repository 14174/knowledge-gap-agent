# 知识闭环与技能门禁模块

本模块实现已审查的知识闭环设计。充分性标签统一为 `enough/partial/missing`，冲突与过时通过独立证据编号表示。运行输入仅含问题与证据；非法模型输出降级为需要研究并保留原响应，不泄漏非法引用。

## 接口与数据流

`assess(question, evidence, model)` 返回充分性、预测缺口、陈旧与冲突引用、置信度、理由及原始模型响应。低于 `0.8` 或非足够、任何缺口均需要研究。

`verify_candidate(text, evidence_refs, evidence, model, *, allowed_sources, now, source_run)` 先确定性检查引用与来源，再调用独立审核模型。返回对象保留请求、原响应和拒绝理由。调用方应传入单独审核调用，不能复用回答文本作为审核结论；通过且置信度至少 `0.8` 才返回凭据。

`SQLiteKnowledgeProvider(path)` 提供 `put_verified`、`entries`、`search`、`close` 和上下文管理。写入重新校验正文、引用、证据正文摘要、来源、运行与审核响应；参数化语句持久化凭据。知识编号由正文和实际出处派生，不依赖临时引用与来源运行。重复写入保留首次记录。检索复用既有确定性检索器，返回稳定排序、分数与 `as_evidence()` 转换。

知识编号将来源编号与对应证据摘要成对排序去重，不能分别汇总来源集合和摘要集合，否则交换两个来源对应的证据正文时会错误合并不同出处。

多来源知识转换为运行证据时保留完整 `source_ids`，首项与兼容字段 `source_id` 一致；旧单来源输入可省略该元组。二次验证检查全部来源准入，身份计算展开每个来源与当前证据正文摘要，模型请求同样保留全部来源。正文摘要仍仅计算正文。

`CandidateSkill` 保存范围、步骤、来源运行、开发任务与版本。`freeze_evaluation` 在读取留出结果前独占创建清单文件，固定候选摘要、分集与阈值；重复调用仅接受相同清单。`evaluate_skill` 重新读取清单，校验分集非空、唯一、互斥、开发隔离、版本及有限得分，再比较目标平均差与回归下降比例。默认门槛为目标差不负、回归下降比例为零。结果仅有 `validated/rejected`，不改变运行策略。

## 拒绝与限制

知识验证凭据是审计绑定，不是密码学授权。恶意代码可自行伪造完整审计结构；模型支持判定也不等于人工批准。证据缺少时效元数据时不能形式证明其未过期。重复写入当前保留首条来源运行；后续来源运行不追加到知识条目。

冻结文件可以检测事后错配，但不能证明调用方在创建文件前从未查看留出答案。独立留出的操作顺序由评测流水线负责。成本字段为调用方提供的统一成本量纲，不能无单价换算金额。

演示五至九使用固定响应或固定配对，输出明确标记为工程演示；演示数值不得写入效果报告。真实效果必须来自独立评测，人工终审状态未改变。

## 验证记录

先创建持久化、凭据篡改、低置信度、越界引用、开发隔离及回归拒绝测试，首次运行因两个新模块不存在而失败。实现后首轮三十六项通过。追加非法布尔响应、裸布尔凭据和磁盘清单篡改测试，观察三项失败后修复。再追加确定性拒绝保留目标的测试，观察失败后补齐审计字段。当前四十六项通过，五个演示实际执行退出码均为零，依赖锁检查通过。

独立规格审查发现来源与摘要分别求集合会丢失对应关系。新增交换来源正文的测试，先观察知识编号相同的失败，再改为来源与摘要成对参与身份计算；四十七项通过，原有跨临时引用和运行去重测试仍通过。

独立质量审查发现多来源知识复用时仅保留首来源。新增回归先实证仅准入首来源仍被错误接受，再贯通完整来源元组和全部准入校验。补充多来源正常验证、身份展开、无效来源元组，以及非默认技能阈值、版本变更与空白任务编号测试。

本轮知识、技能、运行时、轨迹与评测模块联合定向验证共九十七项通过，五个演示重新执行退出码均为零，差异检查通过。来源字段扩展后序列化会包含 `source_ids`，已有单来源输入仍兼容；若外部产物依赖旧序列化字节摘要，应重建相应产物。
