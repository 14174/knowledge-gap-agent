# 证据验证与写回门禁

入口为 `knowledge/verification.py` 的 `verify_candidate` 与 `revalidate`。输入是从真实研究观察提取的候选正文、引文、实际证据、准入来源、审核模型、审核时间与来源运行；不从答案标签提取知识。

## 判据与输出

先检查正文、引文唯一性和可见边界、证据内容摘要、全部来源准入及现有时间约束。结构错误直接返回拒绝记录，不请求审核模型。随后单独请求模型判断支持关系、矛盾或扩展风险，解析严格布尔值；只有接受且置信度至少0.8才生成 `VerifiedCandidate`。

目标摘要绑定正文、有序引文、对应证据摘要、全部来源和来源运行。SQLite 写入前再次解析审核响应、重算目标和凭据；只改变正文再复用旧批准必须失败。多来源不能在复用转换时缩成首来源。

```text
研究观察 → 提取候选 → 确定性检查
                       ├─ 不通过：保留原因与目标
                       └─ 通过：单独模型语义审核
                                  ├─ 拒绝或低置信度：不入库
                                  └─ 通过：重验后入库
```

验证通过说明满足当前证据和模型判断，不代表事实永久正确或真人批准。缺少时效信息时不能形式证明新鲜度；凭据不是抵抗恶意重签名的授权。当前重复知识保留首次来源运行，不提供知识版本撤销或自动过期更新。

## 可执行检查

```powershell
uv run python demo/07_evidence_gate.py
uv run python demo/08_round_trip_reuse.py
uv run python -m pytest tests/knowledge -q
```

07 分别拒绝越界引文和不受支持扩展；08 演示验证后实际新增知识被不同问题引用。两者为固定响应工程演示，真实复用效果另看实验。练习与评分点见[阶段四](../learning/stage-04-knowledge-evolution/GUIDE.md)。
