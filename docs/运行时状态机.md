# 运行时状态机

运行时只接受问题与可见知识，不接受答案、标签、目标类别或缺失主张。`EvidenceView` 的正文以原始 UTF-8 字节计算 SHA-256；任务身份取完整输入的规范 JSON 摘要，每次运行另生成 UUID。系统提示词摘要和客户端完整配置必须与 `RunConfig` 一致。

## 调用与状态

`run_task(task, config, model, research)` 从开始事件进入模型调用。模型仅输出研究或作答动作；单个 JSON 围栏可接受。研究动作调用注入工具并形成观察，下一轮包含全部动作历史与真实观察；作答动作只允许引用已见证据。相同编号的不同正文不能覆盖既有证据。

四种既有事件依次表达开始、动作、工具完成、运行结束。非法动作在结束事件记录失败；模型调用失败仍保存调用错误。停止原因为 `answered`、`max_steps`、`repeated_query`、`invalid_action`、`invalid_citation`、`model_timeout`、`model_error`、`tool_error` 或 `tool_timeout`。查询以 Unicode NFKC、大小写折叠和空白合并规范化后检测重复。

`MessagesClient.from_env(config)` 读取现有接口环境变量；标准库 HTTP 请求绑定模型、温度、输出上限、底层网络超时及重试次数。每次响应保存原始 JSON 和真实用量，成功缺少用量、正文或正常停止原因时拒绝。可选 `before_attempt` 回调在每次真实请求前执行，允许外层预算账本阻止请求；回调不参与传输重试。错误只输出稳定错误类型，不包含接口地址或鉴权头。服务未提供可验证版本时配置使用 `provider-reported-unpinned`，保留服务实际返回模型。

工具采用线程 Future 等待超时。超时只结束运行时等待，无法强杀已经开始的线程，因此真实工具必须自行支持底层超时。HTTP 使用标准库 socket 超时，并非覆盖所有重试的单一总预算。服务端已处理但客户端未收到响应时，用量未知；不得按零成本计入成功调用。

## 保存与重放

`save_run` 用独占创建保存完整结果和规范摘要，同名同内容幂等，不同内容拒绝覆盖。原始请求、响应、重试、观察、事件、最终回答和耗时均保留。计算字段不作为可反序列化输入写回。

`replay_run` 校验摘要后，用保存的响应和观察重新执行状态机，逐项比较配置、输入、调用载荷、动作事件、研究观察与最终输出；网络和真实工具均不参与。原始运行身份与真实耗时不重新生成；事件运行身份另行验证。摘要用于内容完整性检查，不是防恶意重签名的数字签名。

本次只提供完整运行持久化；没有逐步检查点写入与自动断点恢复接口。调用方可保留原始完整记录，不能宣称已经实现逐步恢复。

## 本地演示与验证

```powershell
uv run python -m demo.03_react_loop
uv run python -m demo.04_trace_replay
uv run python -m pytest tests/runtime tests/tracing tests/demo/test_runtime_demos.py -q
```

两个演示使用固定响应，令牌为演示占位值，不代表真实模型效果。本机 HTTP 服务器测试验证真实请求参数、重试、用量解析与网络等待超时；真实服务实验必须另行显式启动，运行时演示不填写 E0 结果。
