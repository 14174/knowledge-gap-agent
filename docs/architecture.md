# 模块架构

当前基线 `cc0dcbe` 已实现配置、轨迹契约、语料、检索和基准门禁。2026-10-15 连续交付按下列边界增量落地，具体实现进度以待办为准。

```text
评测驱动器（独占标签及环境池配置）
  ├─ 问题与可见证据 → runtime → 模型适配器
  │                       ├─ 研究工具（仅允许的证据池）
  │                       └─ tracing（调用、观察、重放）
  ├─ knowledge → SQLite、既有 BM25、充分性与写回验证
  ├─ 完成的回答 → 独立评分器 → 配对统计与报告
  └─ 开发轨迹 → skills候选 → 目标/回归评测 → validated或rejected
```

稳定数据契约不承担运行控制。模型只接收问题与允许证据，不接收答案、类别或主张图。运行结果先落盘再评分；评分不能反向影响当前运行或知识库。主实验每任务独立知识初始状态，只有复用实验允许跨轮写入。

人审批准是正式数据冻结的外部事实，代理自动审查不能代替。探索实验通过专用候选快照与明确状态支持先完成开发，正式冻结器不改写。
