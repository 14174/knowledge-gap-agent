# 知识复用实验报告

结论：工程上发生了持久化、检索与引用，但本批没有证明新增缺失知识被有效复用，也没有减少搜索。不能把数据库增长或命中编号直接包装成学习收益。

## 配对构造

主题05–12的部分覆盖环境各一组，共八组，三次重复，二十四对。第一轮沿用实际 E3 研究、验证和写回的独立 SQLite；第二轮为相关问题的不同表述，有写回与无写回两臂，共四十八次运行，全部完成评分。

两臂共享原本地证据、模型、充分性判断和工具范围；有写回臂只增加同组第一轮真实库检索所得新增条目。问题是同知识范围的近义改写，不是新领域泛化。第一轮失败或没有写入也保留分母，不挑成功组。

## 来源审计：新增编号不等于新增信息

进一步把第一轮候选实际引文通过 `ref_map` 还原到环境来源块，检查是否至少引用原研究池的缺失证据。这是诊断性补充，不改预注册的编号复用定义：

- 二十四组中仅七组写回候选引用了原研究池来源。
- 实际发生引用复用的四组，没有一组属于上述七组；它们的支持来源仍在原可见池。
- 因此16.67%只可称“新增条目引用率”，不可称“新知识学习成功率”。即使来源新增，也不自动证明语义信息增量。

当前提取器从全部研究观察提取一条事实，而研究工具可以再次返回已有可见块；SQLite 又不把初始可见池作为已有条目去重。因此重新存储旧信息可以获得新知识编号，却未补原缺口。该观察指向写回增量性与后续适用性，而不只是检索是否命中。

## 统计补充与边界

按八个主题、每题三重复进行一千次簇采样的补充分析：有写回减无写回成功率为+8.33个百分点，95%区间0至+16.67个百分点；平均搜索增加0.0417次，区间0至0.125次；总运行令牌平均增加394.33，区间−165.71至+1047.29。质量区间未排除零，不能称稳定收益；补充区间不替代主实验预注册结论。

本轮不事后修改提取策略再用同一留出集宣传增益。下一轮应先规定“新观察与原本地证据”的区分、知识适用范围和增量性判据，再使用新的隔离任务验证。当前二十四条高风险候选仍待真人终审；单模型生成、验证与评分也不构成跨模型互证。
