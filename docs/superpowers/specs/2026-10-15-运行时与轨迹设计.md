# 运行时与轨迹设计

## 目标与取舍

实现冲刺第 3–4 天的单智能体循环，复用 `RunConfig`、`TraceEvent` 和规范 JSON。相比直接写一次性评测脚本，循环接口支持离线重放和工具失败；相比通用多智能体框架，仅保留研究、作答两种动作。用户已授权自动设计审查后连续实施。

## 模块与接口

- `runtime/models.py`：不可变 `EvidenceView(ref_id, text, source_id, content_hash)`、`TaskInput(question, knowledge)`、`Action(kind, query, answer, citations)`、`ModelReply(text, input_tokens, output_tokens, model, raw)`、`RunResult`。内部集合使用元组，禁止额外字段；动作按研究/作答验证必填项。证据内容摘要绑定原文，模型只见临时引用、正文及来源，不见标签。
- `runtime/model.py`：`ModelClient.complete(system: str, payload: dict, *, max_tokens: int = 1800) -> ModelReply` 协议；`MessagesClient` 从现有环境读兼容消息接口配置，标准库 HTTP 实现，不新增依赖。传入超时约束真实网络请求；拒绝缺失用量、无文本、截断或不合法响应，不把失败写成零用量成功。错误输出不得包含密钥或鉴权头。保留实际请求模型和返回模型。
- `runtime/loop.py`：`run_task(task, config, model, research, *, system_prompt=DEFAULT_SYSTEM_PROMPT) -> RunResult`。`research(query: str) -> tuple[EvidenceView, ...]` 为依赖注入工具。每轮模型只见问题、本地知识、真实观察和动作历史；解析规范动作 JSON，可处理单个 JSON 围栏，其他格式失败。
- `tracing/store.py`：`save_run(result, directory)` 保存配置、输入、模型原始响应、工具观察、既有 TraceEvent 与最终结果；文件整体内容身份摘要。禁止同名覆盖不同内容。`replay_run(path)` 逐步验证事件序列、观察和动作后返回相同最终回答，不进行网络或工具调用。先实现可审计的完整运行记录；检查点保存为每一步的记录前缀，不承诺尚未实现的自动断点续跑。

## 控制流与失败

`TaskInput` 只包含问题和知识，不带标签关联编号；`task_id` 由该输入的规范 JSON 摘要派生，`run_id` 使用调用时生成的 UUID，因此同输入任务身份稳定而每次运行身份不同。`RunResult` 至少包含 `run_id, task_id, config, task, system_prompt, calls, observations, events, answer, citations, stop_reason, latency_ms`。调用记录保存 system/payload、原始回复或错误、耗时、尝试次数和服务可提供的实际用量；观察保存查询、临时证据编号与正文。不得用保存的最终回答替代执行重放校验。

`MessagesClient.from_env(config)` 将 `model_name, temperature, timeout_seconds, retry_limit` 绑定实际请求。运行开始前校验客户端与配置一致，并验证 `sha256(system_prompt原始UTF-8字节) == config.prompt_hash`；固定响应测试客户端也显式声明同一配置。`model_revision` 无服务版本承诺时填 `provider-reported-unpinned`；报告保留返回模型，不谎称固定权重。网络重试的可获取响应与用量记录进调用日志，无法观测的服务计费明确为未知。

开始事件 → 模型动作 → 工具观察或最终回答 → 终止事件。步数耗尽、重复研究查询、模型非法 JSON、模型超时、工具异常、工具超时和引用越界分别产生稳定停止原因。使用真实耗时与令牌，事件失败必须填错误类型；使用现有四种事件枚举。研究调用预算来自最大步数；模型传输重试只受 `retry_limit` 控制，重试原始错误与用量单独留档，禁止静默反复请求。

采用线程 Future 对注入同步工具实现等待超时，工作线程不可强制终止的限制写入文档；真实研究适配器必须支持底层超时。不运行任意代码或系统命令工具。预算和重复检测针对规范 query，而非动作整个 JSON。

## 验收与边界

无标签输入；成功运行、非法动作、失败工具、重复查询、最大步数、超时、未知引用必须测试。真实接口只由显式实验命令开启，默认测试与演示用标注清楚的固定响应。`demo/03_react_loop.py` 输出成功和失败路径；`demo/04_trace_replay.py` 保存并重放，检查答案与记录一致。阶段报告包含真实命令和结果，暂不写 E0 效果数字。
