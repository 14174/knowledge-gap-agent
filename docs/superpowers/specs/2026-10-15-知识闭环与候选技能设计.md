# 知识闭环与候选技能设计

## 目标和方案

完成冲刺第 5–9 天的知识检索、充分性、验证写回、复用与候选技能门禁。选择标准库 SQLite 加既有 BM25，避免新服务；相比把主张标签做规则判断，使用真实模型从问题推导缺口，保证运行时不依赖评测答案。自动审核由本次用户授权，真人数据终审状态不改变。

## 模块及接口

- `knowledge/store.py`：`KnowledgeEntry` 保存正文、证据引用、来源、正文哈希、来源运行、写入时间及知识编号；`SQLiteKnowledgeProvider(path)` 提供 `put_verified(entry)`、`search(query, top_k=4)`、`entries()`、`close()`。内容去重、稳定排序、参数化 SQL，重开数据库可读取。持久化前验证，不将检索命中自动算作回答复用。知识编号为内容及出处摘要，与单次临时引用分离。
- `knowledge/sufficiency.py`：`SufficiencyDecision(label, missing_claims, stale_ids, conflict_ids, confidence, reason)`，`assess(question, evidence, model)` 使用运行时模型接口，置信度阈值固定为 `0.8`。引用只可来自传入证据；足够标签与非空缺口/陈旧/冲突不兼容。低置信度、任何缺口或冲突都触发研究；`missing_claims` 是模型预测的要点文字，绝不读取标签。模型请求与原响应、用量都留给评测日志保存。
- `knowledge/verification.py`：`verify_candidate(text, evidence_refs, evidence, model, *, allowed_sources, now)`，确定性校验引用存在、来源准入、空文、重复与正文摘要；独立模型判断是否由引文支持、有无冲突/时效风险，输出 `accepted, reason, confidence`。模型的语义批准仍是模型结果。拒绝和通过都留档，只有通过且置信度至少 `0.8` 才能构造可写知识条目。没有时效元数据不能声称形式上证明不过期，模型只能根据正文判断并记录限制。
- `skills/gate.py`：`CandidateSkill` 保存适用范围、步骤、来源运行和内容版本；`evaluate_skill(candidate, target_pairs, regression_pairs, *, max_regression=0.0)` 比较同题得分，目标平均差不得为负，回归任务下降比例不得超过预设阈值，至少有一个来源运行；记录成本差和失败理由。结果仅 `validated/rejected`，不自动修改默认运行策略。配对数据由真实评测生成，演示数据明确是演示。

## 数据流与隔离

写回使用 `VerifiedCandidate` 绑定验证结果和实际目标：目标摘要覆盖正文、按序证据引用、对应证据正文摘要、来源及来源运行。只有 `verify_candidate` 对该精确目标给出通过才产出凭据；`put_verified` 重算目标和凭据摘要，重新校验引用与来源，拒绝正文或证据被更改后沿用旧结果。凭据是进程内审计结构而非密码学信任根，不承诺抵抗恶意程序自行伪造；公开入口不能只凭一个布尔字段绕过绑定。没有通过的候选只留拒绝记录。

`stale_ids` 非空同样触发研究。技能门禁中的每个配对须含 `task_id, split, baseline_score, candidate_score, baseline_cost, candidate_cost, candidate_hash`；两分集非空且编号唯一、无交叉，得分有限并在 `[0,1]`。候选来源开发任务与两评测集无交叉；候选和分集清单摘要在读取留出结果前落盘。缺失、重复、集合不匹配或候选版本不同均拒绝。固定本轮门槛后，留出失败原样报告；根据留出答案修改候选必须另立一轮，不能再声称同轮独立验证。

问题 → 本地 BM25 → 模型充分性 → 需要时研究 → 模型回答 → 单独验证实际研究证据 → SQLite 写入 → 不同问题再次检索并在回答中引用新增知识。主实验每个任务独立初始库，四环境不互相写入；只有显式复用对照允许跨轮读取。

候选技能从开发主题的真实失败轨迹提炼，不能拿评测答案改提示词。主题 01–04 用于开发，05–08 为回归，09–12 为目标集；集合在观察结果前固定。允许候选被拒绝并报告零收益，禁止为了简历数字调门槛。

## 演示和验收

`demo/05_knowledge_provider.py` 展示持久化与分数；`06_sufficiency_gate.py` 展示三类及低置信度；`07_evidence_gate.py` 展示越界/不支持拒绝；`08_round_trip_reuse.py` 展示真实写入 ID 被检索和引用；`09_candidate_skill_gate.py` 展示回归拒绝和只验证不晋升。演示使用明确固定模型响应，不把其数值进入效果报告。

测试覆盖库重开、参数校验、去重、引用越界、标签组合不一致、低置信度、语义验证失败、写回拒绝、技能目标退化与回归、来源不完整。与已有语料层单向依赖，不将数据库与控制流写进数据契约。
