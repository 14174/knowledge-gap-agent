# 第二天语料、检索与基准实施计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `subagent-driven-development`（推荐）或 `executing-plans` 逐任务实现本计划。步骤使用复选框跟踪进度。

**目标：** 建立可复现语料模型、确定性切块与 BM25 检索、可审计的 48 条基准构造和独立复核流程，并补齐阶段一学习材料。

**架构：** 语料层负责来源、切块与主张证据；检索层只依赖语料块；基准层以同一证据池构造知识环境，并把运行输入、评测标签和审计记录分离。所有生产代码严格遵循红灯、绿灯、重构循环，外部模型只产生草稿和复核记录，不能绕过确定性校验或伪造人工结论。

**技术栈：** Python 3.11、Pydantic 2、pytest、标准库 JSON/哈希/数学模块、JSONL

def content_hash(text: str) -> str:
    normalized = normalize_text(text)
    return hashlib.sha256(normalized.encode("utf-8")).hexdigest()
