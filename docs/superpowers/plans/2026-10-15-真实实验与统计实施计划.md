目标：生成可追到原始调用的探索实验与独立重算报告。使用子代理实现，先规格后质量审查。依赖运行时和知识闭环设计接口。

- [x] 为 `eval/dataset.py` 写标签隔离与研究池边界红灯测试，构造候选运行快照及固定主题分集；测试排除池不可访问、运行输入无答案或标注图。
- [x] 为 `metrics.py` 写手算混淆矩阵与零分母测试；实现按主题成簇的一千次配对自助采样并测试恒定差值区间、无配对早拒绝。
- [x] 为 `runner.py` 写固定模型的编排测试，核对搜索次数、每任务库隔离、E2门禁、E3写回与恢复配置冲突。固定响应仅作为工程回归，不写效果指标。
- [x] 实现 `grading.py` 的隔离评分、真实调用日志和结构验证；冻结全部提示词、阈值、分集、语料与代码摘要。
- [x] 在开发主题执行真实接口冒烟并保留结果，修复接口错误后保存协议与代码提交；不以开发成功率替代留出指标。
- [x] 执行三次32题四变体、八组复用配对及一个候选技能留出评测，保存所有失败和真实用量。预算耗尽或服务失败时保留部分结果并明确缺失，不补造重复。
- [x] 实现不联网的报告重算命令与 `demo/10_reproduce_report.py`；汇总E0基线、充分性、复用、技能及总报告。
