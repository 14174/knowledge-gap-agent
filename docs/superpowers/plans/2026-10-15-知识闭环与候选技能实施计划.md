测试应验证的行为示例：

```python
def test_verified_entry_survives_reopen(tmp_path):
    provider = SQLiteKnowledgeProvider(tmp_path / "knowledge.db")
    entry = provider.put_verified(candidate)
    provider.close()
    reopened = SQLiteKnowledgeProvider(tmp_path / "knowledge.db")
    assert reopened.search("元组", top_k=1)[0].knowledge_id == entry.knowledge_id
```

`candidate` 必须在测试中通过真实确定性校验与标注为固定响应的独立模型验证构造；禁止用标签主张代替生产运行时判断。
