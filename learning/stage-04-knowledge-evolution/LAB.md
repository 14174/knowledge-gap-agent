# 阶段四实验

统一记录假设、变量、控制、预期、实际、证据和结论；演示固定响应不参与效果统计。

## 基础实验

运行07、08，定位一个确定性拒绝、一个语义拒绝，以及数据库条目产生后被回答引用的路径。记录来源运行、知识编号、引文编号，解释三个身份各自指什么。

## 单变量实验

用固定响应审核同一候选，仅把置信度0.9改为0.79。证据、来源和正文保持不变。预期低置信度返回拒绝、库条目数仍为零；原响应与拒绝原因可读。恢复后复验。

## 故障实验

先获得一个合法候选，用不验证的复制操作只改变正文，再交给真实 `put_verified`。预期目标重算失败，不能插入。然后阅读多来源回归测试：交换来源与证据的对应关系为何必须改变稳定知识编号？

运行 `uv run python -m pytest tests/knowledge -q`。不要修改仓库真实候选数据来制造失败，测试全部使用临时数据库。
