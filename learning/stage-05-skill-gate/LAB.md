# 阶段五实验

记录假设、修改变量、控制变量、预期、实际、原始记录和结论。固定配对仅验证门禁实现。

## 基础实验

运行09，对照 `target_delta`、`regression_rate`、`status`。定位独占创建的清单和候选摘要，解释通过为什么不自动晋升。

## 单变量实验

保持候选、分集和全部配对得分不变，只在新实验清单里将允许回归比例从0改为0.25。比较门禁判断。禁止覆盖旧清单；解释这次改变的是判据，不是证明候选变好了。

## 故障实验

冻结候选后，只修改一条配对记录的候选摘要。预期拒绝，即使所有得分提高。再移除一个预注册配对，观察统计函数将区间标为不可用。

有真实批次时，在两个新目录分别离线重算报告，比较 JSON 内容摘要。重算期间禁止传入 `--live`；重算不应增加请求账本计数。无真实批次时只做门禁和指标手算，不创建假效果报告。
