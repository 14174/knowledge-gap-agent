# 阶段二实验

统一记录：实验假设、修改变量、控制变量、预期、实际、轨迹位置、结论。固定模型演示只验证工程行为，不填真实效果指标。

## 基础实验：研究后作答

运行 `uv run python demo/03_react_loop.py`，沿 `demo/fixed_runtime.py` 找到研究与作答两条固定响应。记录输入问题、研究查询、工具返回引用及最后引用。解释为什么作答事件必须发生在工具观察之后。随后运行 04，确认重放没有创建新的模型请求。

## 参数实验：只改变步数

在临时副本或学习分支中，把演示配置的 `max_steps` 改为 1，保持问题、两条响应、工具、提示词不变。预期研究已执行但没有作答机会，停止原因为 `max_steps`，没有最终答案。复原后再次运行，比较事件和调用次数，而不是比较随机运行编号。

## 故障实验：引用没有看到的证据

只把固定答案的引用改成一个从未出现在本地知识或工具结果里的编号，运行 03。预期停止 `invalid_citation`。若你同时改工具结果就破坏了单变量对照。复原后运行：

```powershell
uv run python -m pytest tests/runtime tests/tracing tests/demo/test_runtime_demos.py -q
```

挑战：保存一个成功记录，将结束事件改成失败但保留旧摘要，验证重放拒绝。再查看测试如何在重新计算外层摘要后仍检查行为不一致，说明两层检查分别防什么。
